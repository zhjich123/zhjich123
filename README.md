# 媒体嗅探器 Media Sniffer Pro

一个功能强大的 Tampermonkey / ScriptCat 油猴脚本：抓取网页中的图片（含多尺寸、懒加载与背景图）、视频、音频与 m3u8 流媒体，支持视频链接解析与弹窗播放、放大预览（手机端底部弹层 / 电脑端居中对话框，含下载、复制地址、录制媒体流与提取封面）、DASH 音视频独立播放与自动合流、AES-128 解密、批量下载队列（可一键全停）、Aria2 / WebDAV(NAS) 推送与备份管理、白 / 黑名单筛选、可自定义的更新源、插件市场（支持本地导入与第三方解析器），并提供多引擎翻译、听歌识曲、转文字 + AI 摘要、6 种界面风格与多语言界面。

> **当前版本：v1.24** · [下载最新版](https://github.com/zhjich123/zhjich123/releases/latest)

## 功能特性

### 🔍 资源嗅探

- **四类资源一键抓取** —— 图片、视频、音频、m3u8 流媒体
- **网络层拦截** —— 同时覆盖 DOM 扫描、XHR / fetch 拦截与媒体元素探测，动态加载的资源也能抓到
- **页面链接解析** —— 哔哩哔哩、抖音、快手、小红书、微博、知乎、微信视频号
- **跨域兜底** —— 受 CORS 限制的资源由脚本代为请求
- **图片抓取更全面** —— 多尺寸图片列表、`<picture>` 多源图片、懒加载图片、页面分享图，以及多层与伪元素背景图
- **流媒体覆盖更广** —— 除直接地址外，通过 MediaSource 播放的分片流与 blob 资源也能识别并正确归类
- **虚拟列表** —— 数千条资源滚动依然流畅，不再一次性渲染全部卡片

### 🎬 视频解析与播放

- **一键批量解析** —— 视频页面链接可批量取出真实播放地址
- **解析后一键播放** —— 点「解析」取出真实地址后按钮变「播放」，点一下即弹出播放窗口，可直接下载
- **画质与分 P 切换** —— 在同一弹窗内切换清晰度、切换分 P
- **DASH 音视频独立播放** —— 画面与声音分轨的视频，预览时自动同步播放独立音频轨
- **DASH 音视频自动合流** —— 下载时自动合并视频轨与音频轨，不再出现「有画面没声音」
- **AES-128 加密流解密** —— 支持加密 m3u8 分片解密与合并，内置两套解密实现，在无安全上下文的老旧环境下同样可用
- **放大预览** —— 图片、视频、音频、m3u8 均可在面板内放大查看（自下往上滑出，手机端底部弹层、电脑端居中对话框），预览内可直接下载、复制地址、新标签页打开、录制媒体流与提取封面，并显示地址、大小、时长或图片尺寸

### ⬇️ 下载与保存

- **多种下载方式** —— 单个下载、下载选中、下载全部、双击卡片直接下载
- **批量下载队列** —— 并发数、重试次数、请求间隔均可自定义，支持暂停 / 继续 / 取消 / 重试
- **队列一键全停** —— 队列头部一键停止全部任务，不必逐个取消
- **下载完成通知** —— 下载结束弹出系统通知，切到别的页面也不会错过
- **进度可视化** —— 实时进度、下载速度、预计剩余时间
- **生成下载脚本** —— 一键生成 aria2 / wget / curl 脚本，跨域资源也能交给外部下载器
- **Aria2 推送** —— 直接推送到本机或远程 Aria2
- **WebDAV 后端** —— 下载完成后自动保存到 NAS，配置可备份与恢复
- **备份文件管理** —— 直接查看 NAS 上的备份文件并逐个删除
- **文件名模板** —— 支持域名、日期、序号、后缀等占位符自定义

### 🎨 界面与主题

- **6 种界面风格** —— 普通 / 澎湃 OS（HyperOS）/ iOS 27 液态玻璃 / 新拟物 / 粗野主义 / 终端
- **配色方案** —— 内置多套配色，支持添加、编辑、删除自定义渐变主题色
- **三种主题模式** —— 亮色 / 暗色 / 跟随系统
- **动画与交互反馈** —— 标签页左右滑动切换、预览弹窗自下往上滑入、卡片悬停与入场动效、点击波纹、选中回弹、进度条流光、悬浮球光环
- **面板自定义** —— 位置记忆、边缘吸附、最小化、拖拽调整宽度、设置分组折叠

### 🧩 选择与管理

- **选择模式** —— 长按或按钮进入，支持点选、全选、反选、清除、Shift 连选

#### 🔴 修复：部分按钮上直接显示 SVG 源码

有用户反馈某些按钮上出现了一长串 `<svg style="display:block…" …><path d="M11 4H4a2 2 0 0 0-2 2v14…`。

**两层根因**：① **语言表里内嵌了图标** —— `LANG.strings` 有 **81 处** 把 SVG 拼进文案值；
② **渲染出口用了 `textContent`** —— 选区工具栏 `btn()`、Cookie/Storage `mkBtn()`、
翻译页 `makeBtn()`、其他操作 `mkOBtn()` 都把语言值当 HTML/文本直接赋给元素。

**修法**（按「语言表只存纯文本」的约定彻底收口）：

- 语言表 **81 处图标前缀全部剥掉**，现在自检 `内嵌 ICONS: 0 | 字面 <svg: 0`
- 新增 **`UI.iconTextEl(icon, text)`**：图标走 `innerHTML`（内置常量）、
  **文案走 `textContent`**，用 DOM 拼而不是字符串拼接
- 5 个按钮工厂全部改用它，彻底不再 `innerHTML = label`
- **19 处调用点把图标补回原位**（视觉不退化）：`genScript` / `dlMerge`(×2) /
  `genScriptBtn`(×2) / `m3u8Title` / `m3u8Detail` / `encrypted` / `advFilterTitle` /
  `speakBtn` / `importConfig` / `copyResult` / `copyCookieStr` / `addCookie` / `clearSite` /
  `addItem` / `clearAll` / `lsTitle` / `lsCount`
- Storage tab 的统计行与两个分区标题原来走 `textContent` 直赋，改成 `iconTextEl` 组合
- 顺手把设置页最后那行「语言值进 innerHTML」拆成两个 `textContent` 的 div

**守卫加了一档**：`LANG.assertPlainText()` 原来只查 `<svg`，现在查**任何标记**；
翻译页介绍文案里内嵌的 `<br/>` 改成 `\n` 分段 + 渲染处按行生成 div。
